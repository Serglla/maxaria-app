Cada lista parte de una base —un nivel (Costo, Minorista, Revendedor, Mayorista, VIP) u otra lista— y le aplica un % de ganancia limpia del vendedor sobre el precio final. Luego se asigna a un cliente desde la pestaña Usuarios (columna "Lista de precios"). El precio que ve el cliente es base / (1 − ganancia/100), redondeado, de modo que precio_venta − ganancia% = precio_base. Ej: base $1000 con 10% → vende a $1111 (gana $111 limpios). Con base en otra lista, el % se aplica sobre el precio de esa lista (puede ser negativo, ej: "SuperVip" = lista Vip con −2%) y ese % es la comisión que cobra el vendedor. Debajo, la columna Ganancia aclara cuánto queda el precio final respecto del nivel raíz de la cadena (dato informativo, no es la comisión).
