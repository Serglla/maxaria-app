Nombre de la aplicación

Este nombre aparece en el encabezado del catálogo, en la pantalla de login y en el panel de administración. Máximo 60 caracteres.

WhatsApp para recibir pedidos

Este es el número al que se abre WhatsApp cuando un cliente envía su pedido. Formato internacional sin + ni espacios (ej: 5493442000000).

Ver cambios · Visibilidad

Cuando subís un Excel de precios, los clientes que estén dentro de los niveles seleccionados ven el botón Ver cambios en el catálogo con el historial de las últimas 10 actualizaciones: cambios de precio, reingresos (productos que volvieron de stock cero) y productos nuevos.

El admin siempre puede ver esta solapa, sin importar la configuración. Si no marcás ningún nivel, ningún cliente la ve.

Backup manual de usuarios

Exportá un JSON con todos los usuarios (incluyendo sus contraseñas hasheadas) como respaldo manual. Si en algún deploy se pierden, podés re-importar este archivo y los usuarios vuelven sin necesidad de recrearlos.
El JSON tiene info sensible (los hashes), guardalo en un lugar privado.

El import hace UPSERT por username: usuarios existentes se actualizan, nuevos se crean. Nunca borra usuarios.
